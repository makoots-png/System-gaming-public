# Who drew the icons

The pictures of `icons.ts` beside this file. The licence asks for this file and for the line the app shows on the Rules
page's foot: "Icons made by Lorc and Delapouite, from game-icons.net, under CC BY 3.0."

## The licence

52 icons are by Lorc (http://lorcblog.blogspot.com) and 22 by Delapouite (https://delapouite.com), from
game-icons.net (https://game-icons.net, the repository https://github.com/game-icons/icons), under the Creative Commons
Attribution 3.0 licence (https://creativecommons.org/licenses/by/3.0/). The set's `license.txt` asks: "Please, include a
mention 'Icons made by {author}' in your derivative work." The licence itself asks that a work which uses them name the
author, the title of each work and where it is found, give the licence's address, and say that the work was changed.
Each was changed: its path flattened to straight segments, scaled onto the 24 grid, simplified until it fits 400
characters, and its specks under half a square unit dropped. Only the path data is copied: no file of the set is
fetched or shipped.

The twelve emblems (star to fang) were drawn for the game before the set; the 9 marked "drawn here" were drawn
for it to the same grid, where the set had none that reads at 14 px.
