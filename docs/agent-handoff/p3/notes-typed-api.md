## Step 3: the API table
- `src/core/api.ts`: one type per `app.api` name (17) and `AppApi`. All live in this one file: no API here is a thin front over one pure module (each view mixes the store, windows and DOM; sync's pure parts are four machines), and `AppApi` must be in core, which cannot import edge, so `SyncApi` is here too. One file is also the one place a reader opens (`principle-minimize-reader-load`). Types are as precise as the data: where a view builds a shape only it reads, the type says `unknown` or a record rather than guessing (`principle-type-system-discipline`).
- TypeScript callers: `SyncApp.api` in sync.ts is `Partial<AppApi>`, so the `app.api.sync = { ... }` registration is checked against `SyncApi` by tsc (it found one gap: `roster` answered `state: string`; now typed). `ApplyDeps.hunter` in room-events.ts is `RoomHunter`, a `Pick` of `HunterApi`, and `issueQuest` is `QuestsApi['issue']`; the hand-written copy of those signatures is gone.
- Unresolved 1 (sync.ts handed the whole hunter API to the appliers): the `hunter` getter now builds the slice by naming its eight members off `const h = app.api.hunter!`. deps.ts learned one pattern for that: an alias may end in TypeScript's non-null `!`. The map now shows sync.ts using each of the eight.
- Unresolved 2 (hunter.js `app.api[n].bonuses`): the bonus providers are a written-out list, `[app.api.inventory && app.api.inventory.bonuses, app.api.skills && app.api.skills.bonuses]`. `skills.bonuses` left UNUSED.
- deps.ts reads `AppApi` and each type it names with the same `readTypeTable`; an entry naming something that is not a type literal in api.ts goes to Unresolved. The map's API tables gain a Signature column; `bun run deps -- combat.add` prints the signature and its doc.
- Three new tests: AppApi lists exactly the registered names; every member used is declared; each type declares exactly what its module registers. Checked by mutation: deleting `isActive` from `CombatApi` failed the second (table.js:294) and the third.
- Allow lists now: UNHEARD, UNSENT and UNRESOLVED empty; UNUSED holds only `quests.complete` (step 1). `bun run test`: 849 pass. room-sync + character: 13 passed.
