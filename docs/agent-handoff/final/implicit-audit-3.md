hit, so an implicit thing with no keyword is still unseen. This audit reads the listed files top to bottom and lists
what is still implicit, without repeating the second audit's rows (N1 to N20, rows 41, 42, 51, 57, 84) or the
leftovers' rows 6 to 12, which are being done now.
